### Hi, I'm Abdullateef Tijani 

A Biochemistry graduate building at the intersection of Machine Learning, AI, Bioinformatics, and Computational Biology.

My focus is on designing and applying AI/ML systems to problems that matter in biology and medicine, protein function prediction, multi-omics data analysis, transcriptomic pattern discovery, and building computational tools that work in resource-limited environments, not just on expensive GPU clusters.

### Computational Biology & Bioinformatics

Comfortable across the full bioinformatics pipeline: transcriptomics (differential gene expression, RNA-seq analysis), metabolomics, proteomics (protein feature engineering and function annotation), and survival analysis in clinical genomics datasets. I use GO and KEGG pathway enrichment to move from a list of genes or proteins to a biological story, working in both Python and R depending on what the problem demands, and i care about the statistical reasoning behind the tools i use, not just how to run them.

### Machine Learning & Deep Learning

I work primarily in PyTorch and TensorFlow, building deep learning systems from the ground up rather than plugging data into existing frameworks. My experience includes designing multi-layer perceptron ensembles, handling extreme class imbalance through custom focal loss functions and dynamic class weighting, automated threshold calibration pipelines, and hierarchical inference architectures that cut computational cost without sacrificing prediction quality.

### Turning Models Into Usable Tools

Building a model is only half the work. I package my analysis pipelines as FastAPI backends with React frontend so the tools i build are actually usable by other researchers and clinicians, not just runnable from my own terminal. I think about deployment from the start of a project, not as an afterthought.

### Wet Lab Foundation

I'm not purely a computational person. Hands-on clinical laboratory training, haematology, clinical chemistry, microbiology, histopathology, means i understand the biological context behind omics data: where it comes from, what can go wrong during collection, and why certain patterns show up in the numbers.
